# Internal records

Not part of the published documentation site. These are the build records kept for
provenance — how each release was scoped and sequenced — written for the people doing
the work at the time, in the tense they wrote them.

| File | What it records |
|---|---|
| `brief.md` | The v0.1 build instructions |
| `milestones.md` | M1–M9, the v0.1 increment sequence |
| `plan-0.2.md` | N1–N7, the 0.2 increment sequence |
| `plan-1.1.md` | N1–N4, the increment sequence for the release that shipped as 2.0 |

The public record of *why* the design is what it is lives in
[architecture/decisions.md](../docs/architecture/decisions.md). If something in here
contradicts a published page, the published page wins.
