# @orpc-agent/mcp

Model Context Protocol server adapter for [oRPC Agent](https://orpc-agent.dev) runtimes: expose governed capabilities as MCP tools.

> Independent community project, not affiliated with or endorsed by the oRPC maintainers.

## Install

```bash
pnpm add @orpc-agent/mcp @orpc-agent/core @modelcontextprotocol/sdk
```

Docs: [MCP adapter guide](https://orpc-agent.dev/adapters/mcp) · [repository](https://github.com/Wiseair-srl/orpc-agent)
