# @orpc-agent/mcp

Model Context Protocol server adapter for [oRPC Agent](https://github.com/Wiseair-srl/orpc-agent) runtimes: expose governed capabilities as MCP tools.

> Independent community project, not affiliated with or endorsed by the oRPC maintainers.

## Install

```bash
pnpm add @orpc-agent/mcp @orpc-agent/core @modelcontextprotocol/sdk
```

Docs: [MCP adapter guide](https://github.com/Wiseair-srl/orpc-agent/blob/main/docs/adapters/mcp.md) · [repository](https://github.com/Wiseair-srl/orpc-agent)
