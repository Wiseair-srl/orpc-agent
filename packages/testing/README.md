# @orpc-agent/testing

Deterministic governance testing for [oRPC Agent](https://orpc-agent.dev) capabilities — no model, no network.

> Independent community project, not affiliated with or endorsed by the oRPC maintainers.

## Install

```bash
pnpm add -D @orpc-agent/testing @orpc-agent/core
```

Docs: [testing adapter guide](https://orpc-agent.dev/adapters/testing) · [repository](https://github.com/Wiseair-srl/orpc-agent)
